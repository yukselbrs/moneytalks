# 02-urun — Ürün Dokümanları

Ürün spec'leri, özellik tanımları ve PRD'ler burada tutulur.

## Amaç
Yeni bir özellik veya endpoint yazmadan **önce** ilgili spec buraya yazılır. Kod, spec'i takip eder — tersi değil.

## İçerik türleri
- Özellik spec'leri (ör. KAP bildirim özetleyici, "neden düştü/çıktı" kartı, portföy karnesi)
- Kullanıcı akışları ve onboarding
- Fiyatlandırma / paket tanımları
- SPK uyumlu dil kuralları (özellik bazında)
