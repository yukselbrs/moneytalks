# Faz 4 / Görev 19 — Fon Kategori Kıyası (B.12)

**Tarih:** 15 Temmuz 2026 · **Durum:** Tamamlandı

/api/fon/[kod] yanıtına `kategoriKiyas` eklendi: aynı kategorideki fonların (≥5 fon şartı) medyan gider oranı + medyan 1Y getirisi — zaten bellekteki snapshot satırlarından, ek sorgu yok. Fon detayının Genel Bilgiler kartına nötr kıyas satırı: "gider oranı medyanın üstünde/altında" (teşhis dili, "pahalı/kötü" yargı sıfatı yok) + bilgilendirme disclaimer'ı.
