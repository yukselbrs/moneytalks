# 05-gunluk — Günlük Notlar

Günlük çalışma logları ve oturum notları burada tutulur.

## Amaç
Ne yapıldığının kronolojik kaydı. Handoff dokümanları bu notlardan derlenir.

## Format (öneri)
Dosya adı: `YYYY-MM-DD.md`
- Bugün yapılanlar
- Açık kalan / bekleyen işler
- Karşılaşılan sorunlar ve çözümler
